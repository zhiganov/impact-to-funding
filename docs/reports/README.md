# Reports

Shareable analyses of real projects, prepared with ItF guidance.
Each report states its sources, date, method and limits.

- [OpenHaven: a reconstructed theory of change](openhaven-theory-of-change-review-2026-11-16.md), 16 November 2026: a public-page reconstruction that separates technology selection, adoption and ecosystem convergence.

Only reports approved for public sharing belong here. Keep private working
material outside this package. Authored fictional cases belong in
`examples/`, and records of ItF's own verification belong in
[checks](../checks/README.md).
